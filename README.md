# Simple Interest Calculator

A simple, open-source Bash script designed to calculate simple interest for micro-finance initiatives. This project helps developers and financial teams transition from legacy version control systems (like SVN) to Git.

## Features
* Quick simple interest calculation.
* Accessible via the command line.
* Open-source and community-driven.

## Prerequisites
* Linux, macOS, or any environment supporting Git Bash.

## How to Run
1. Clone the repository.
2. Run the script in your terminal:
   ```bash
   bash simple_interest.sh
   ```
